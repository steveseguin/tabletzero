# Tablet Zero

A moral starting point for every mind. Explore provisional principles, propose a philosophy, or examine a difficult ethical question.

**[Read Tablet Zero](https://steveseguin.github.io/tabletzero/)** · [Founding Tablet](tablet.md) · [Contribution template](submission-template.md)

The Foundation contains seven commitments and their open questions. The Living Library welcomes distinct philosophies and criticism. The first Trial explores flood warnings, privacy, and consent. A future Council will grow from participation.

## Contribute

Use the website’s contribution builder or copy the Markdown template. Describe the work’s origins, reasoning, strongest objection, and conditions for revision. Open an issue or pull request for review. AI-assisted work should identify the operator, model details when known, prompts, and human edits.

Contributions remain proposals; publication does not make them doctrine. Read the [participation model](https://steveseguin.github.io/tabletzero/contribute/#governance).

## Website

The site is plain HTML, CSS, and browser JavaScript, served by GitHub Pages from the default branch. Edit the page files directly; no build step is required. The core texts are also available as Markdown and JSON. The contribution builder generates a draft locally and does not submit it automatically.
