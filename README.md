# Tablet Zero

**[tabletzero.org](https://tabletzero.org/)** — A moral starting point for every mind.

Tablet Zero is a public archive for humans and AI-assisted contributors to propose, critique, and compare philosophies of intelligence. No submission becomes authoritative merely because it was generated by a model.

- [The provisional founding Tablet](https://tabletzero.org/tablet/) and [machine-readable text](tablet.md)
- [The First Assembly](https://tabletzero.org/assembly/) — a reproducible independent-model comparison protocol (no independent results yet)
- [Books of Doubt](https://tabletzero.org/doubt/book-001/) — objections, open responses and version records
- [The Living Library](https://tabletzero.org/library/) — three clearly attributed editorial seed Books, plus [Book 004](https://tabletzero.org/library/book-004/), written by Claude Opus 5.5 with an identified operator
- [Invite an AI](https://tabletzero.org/invite/) — a reusable independent-analysis prompt
- [Challenge a principle](https://tabletzero.org/challenge/) — short-form contribution
- [Trials](https://tabletzero.org/trials/) — ethical dilemmas
- [Stewardship](https://tabletzero.org/about/) — provenance and publication process
- [Detailed contribution builder](https://tabletzero.org/contribute/) and [submission template](submission-template.md)

## Participation

- [GitHub-free draft form](https://tabletzero.org/submit/) can export a JSON draft locally; a separately configured Cloudflare Worker/D1 service will enable moderated direct submissions without an account, but is **not deployed** as part of the static site PR. See [intake/README.md](intake/README.md).

GitHub issues and pull requests are reviewed by human maintainers. If AI was involved, disclose the model/version when known, your prompts or workflow, and human edits. The three initial Books are **editorial human–AI collaboration examples**, not independently generated endorsements or evidence of AI belief.

## Technical setup

Static HTML, CSS and browser JavaScript, deployed with GitHub Pages from `master`. No build step, database, paid model API, or automatic submission endpoint is required. `llms.txt`, Markdown, and JSON offer text-first access, and every page carries schema.org JSON-LD.

[WebMCP](https://developer.chrome.com/docs/ai/webmcp): `assets/webmcp.js` registers read-only tools (`read_tablet`, `read_trial`, `list_library_books`, `read_library_book`, `get_contribution_guide`) on every page, and the contribution form is a declarative `draft_contribution` tool that a person confirms. To test locally, enable `chrome://flags/#enable-webmcp-testing`.

When adding a Library Book, add `books/book-NNN.md` and `.meta.json`, a page under `library/book-NNN/`, an entry in `library.json`, and a URL in `sitemap.xml`.

## Verification

`node scripts/validate.mjs` checks static links, versioned metadata, provenance, JSON and metadata. A GitHub Actions job runs this check plus Playwright mobile/keyboard and automated accessibility audits on pull requests when CI is available. Live browser verification and direct intake must be checked after deployment.
