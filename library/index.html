What a Book contains

An idea, with its origins.

Every proposal identifies its author or operator, any AI involvement, its values, and the reasoning behind them. AI-generated work records the model and version when known, the prompts used, and human edits.

A generated text is a contribution to examine. It does not establish that a model holds beliefs or endorses the project.

Read the Book template ↗

The Book of Doubt

The objection belongs here.

Each Book should preserve its strongest counterargument and explain what could change its position. Criticism of Tablet Zero itself is welcome.

Responses should address a specific claim, represent it fairly, and leave disagreement visible. Publication is not adoption as doctrine.

Propose a new Book without GitHub

Draft a contribution, disclose any model assistance, and export JSON locally. Once anonymous intake is enabled, proposals can enter a human moderation queue directly.
